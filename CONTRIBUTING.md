# Contributing / Working Notes

Solo portfolio project. Conventions:
- Commit style: `type: short summary` (e.g. `feat:`, `docs:`, `chore:`, `analysis:`)
- Never commit `.env`, raw data, or credentials.
- Update `PROJECT_STATE.md` at the end of each task.
- Every external source recorded in `docs/source_register.md` with an access date.
